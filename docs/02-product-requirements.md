| ID | Requirement | Target |
|----|-------------|--------|
| NFR-001.1 | First Contentful Paint (landing) | < 1.5s |
| NFR-001.2 | Time to Interactive (game page) | < 3s |
| NFR-001.3 | Stockfish move at depth 15 | < 2s (client) |
| NFR-001.4 | Gemini API response (coach explanation) | < 5s P95 |

| ID | Requirement | Target |

## Constraints

1. **Vercel-only deployment** — No separate backend servers.
2. **Client-side Stockfish** — Backend never computes engine moves.
3. **Server-side Gemini** — All AI calls proxied through API routes.
4. **Feature-driven architecture** — No monolithic `components/` dump.
5. **Working state per phase** — Each implementation phase is deployable.

---

## Acceptance Criteria (Product-Level)

The product is considered v1-complete when:

- [ ] All P0 functional requirements implemented
- [ ] All five game modes playable end-to-end
- [ ] Authentication flow complete
- [ ] Games persist and appear in history
- [ ] Analysis mode produces Stockfish stats + Gemini narrative
- [ ] Training mode generates at least one personalized lesson
- [ ] Dashboard displays user progress
- [ ] Deployed to Vercel production with Neon database
- [ ] No P0 security vulnerabilities
- [ ] Core flows pass E2E test suite
